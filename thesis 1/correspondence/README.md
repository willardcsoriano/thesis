## Overview

This folder holds material prepared for specific messages to the adviser and course faculty, as opposed to the proposal document itself (`../consolidated/`). Its first contents are before/after visuals for the 2026-10-08 defense follow-up: real screenshots of the effect analysis reasoning about everyday requests with composition (wrapper, `find -exec`, `find -delete`, `xargs`, `eval`, shell `-c`, and loop resolution) enabled versus disabled. They answer the defense's "is this really more than the underlying rule table" question with a picture rather than only a number. Nothing here is submission content; the same result already lives in the proposal as Thesis 1 §3.1(h) and Table 3.5, and in `docs/open-problems.md` row 38.

## How the screenshots were made

Every screenshot is real terminal output from `prototype/cmd/effexplain`, unedited apart from trimming empty margin. The five-example image runs it with `-dir` against `~/Documents/SynapseOS-Demo-Everyday/`, a folder of ordinary sample files (screenshots, photos and their copies, zip files, Word drafts, an `OldPhotos` folder), so the screenshots name recognisable files. The analysis only reads that folder; nothing in it is changed, and paths are printed relative to it, so no home-directory name appears. The single-example images use effexplain's own generated fixture instead, which is why their paths begin `/tmp/effexplain-…`. `-nocompose` produces the "before" side.

Captures were made the same way as the defense deck's: a real pty via Python's `pty` module, rendered with `pyte` and Pillow, no X11 or screen recording. The page around them is HTML and CSS in the deck's light palette, rendered to PNG at 2x with Chromium through Playwright. The capture and layout scripts are scratchpad-only, one-off tooling, not part of this repo.
