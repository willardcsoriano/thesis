## Overview

This directory is intentionally empty. Chapter 2 (Review of Related Literature) and Chapter 3 (Methodology) were drafted here as `summative-assessment-2.html` and `summative-assessment-3.1.html`, but neither was ever individually submitted through the course portal — only Chapter 1 and the consolidated Chapters 1-3 monograph were actually submitted. Keeping two editable copies of the same content (the standalone drafts and the consolidated document) risked drift between them, so the standalone drafts were deleted (Session 13). Chapter 1's own standalone HTML was later retired the same way (Session 14), and so was the consolidated document's flat, non-paged variant — the paged variant is now the sole living document for Chapters 1-3, maintained by hand.
