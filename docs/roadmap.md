## Overview

This file is the single place to check where SynapseOS stands right now, across all three horizons the project spans — from the thesis-scoped prototype, through deferred post-thesis product ideas, to the long-term vision. It holds no detail of its own: every row is a pointer to the file that owns that horizon's actual content, so status never has two places to go stale in. Read `vision.md` first for *why* any of this exists; come here when the question is *where things stand* instead. For anything more specific than a one-line status, follow the link — this page stays a dashboard, not a duplicate.
