## Overview

This directory is a placeholder for the **Thesis 2** course, which follows Thesis 1 in the program (itself following Research Methods, `research-methods/`). It is currently empty and exists only to reserve a stable path in the repository layout ahead of that course starting. Once Thesis 2 begins, this directory should hold the same kind of structure `research-methods/` uses — course references and your own submissions — adapted to whatever that course actually requires. Nothing here should be treated as thesis content yet; the real proposal chapters live under `research-methods/module 2/` and `research-methods/module 3/` until Thesis 1 and Thesis 2 supersede them.
